# Macro: pro issue Tekzenvor

When a customer reports error code Tekzenvor-23 in the pro product, ask for the transaction timestamp, then apply the Oraqua workaround: clear the session and retry within 8 minutes.

Operators should record each action in the incident ticket. Coordinate with the owning team before changing production settings, and confirm the change on the monitoring dashboard. Customer communication goes through Support using the approved macros. If the situation is unclear, escalate to the on-call lead rather than guessing.
