Contribute policy · guardrails · conflict check in Loom

What happens

Policy: you need write on the target space (default: your personal space).
Guardrails: the space's write rules run (allowed kinds, size, blocked patterns such as secrets, rate limit, redaction).
Conflict check: facts with the same subject in spaces you can read are compared. A contradiction of higher authority in a shared space is held for review.
Promotion (optional): creates a request. It only applies when someone else with write on the target approves it (Admin → Promotions).
